Vice Frame is a GTA-style cover art maker that runs entirely in the browser: drop in your own photos, arrange them across poster panel layouts (Vice hero stack, 2x2 grid, trio strips, full-bleed solo), drag to reposition and scroll to zoom each panel, dial in the Vice City sunset grade, and set your caption in heavy outlined display lettering with a letterspaced kicker. One click exports a share-ready PNG in the common post sizes — 1080 x 1080, 1080 x 1350 and 1920 x 1080. Everything is original (no game logos, artwork or fonts), works fully offline from static files, and your photos never leave your machine. Five sample photos made with an image model are built in so a first cover takes seconds.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
